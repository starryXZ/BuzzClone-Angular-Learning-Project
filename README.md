## 🚀 Sobre o Projeto

O **Clone BuzzFeed** é uma aplicação desenvolvida com **Angular**, focada em **boas práticas de componentização, modularidade e escalabilidade**.

A proposta é recriar a experiência dos quizzes do famoso site **BuzzFeed**, permitindo ao usuário responder perguntas dinâmicas e visualizar o resultado final.

## 🧠 Tecnologias Utilizadas

| 🚀 **Tecnologia** | 📄 **Descrição** |
|--------------------|------------------|
| **Angular 17+** | Framework front-end para criação de SPAs modernas |
| **TypeScript** | Linguagem com tipagem estática e recursos de OOP |
| **HTML5** | Estruturação dos componentes e páginas da aplicação |
| **CSS3** | Estilização responsiva e modular dos elementos |
| **JSON** | Armazenamento e manipulação dos dados dos quizzes |
